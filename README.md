## 📱 Featured Project

### Fund Flow

**Fund Flow** is a production-ready offline-first personal finance Android application built with Kotlin and Jetpack Compose.

Available on Google Play and actively maintained.

The application helps users:

* Manage multiple funds.
* Track expenses and transactions.
* Generate financial reports.
* Backup and restore their data.
* Keep all financial information private and stored locally.

Key principles:

* 🔒 Privacy First
* ⚡ Offline First
* 🔄 Reactive State Management
* 🏗️ Modern Android Architecture
